# 후속 분석 계획

공개본은 합성 샘플로 전처리, 날짜 단위 비교, 모델 검증과 수송 용량 계산을 실행합니다. 다음 단계는 원본 자료를 다시 확보한 뒤 실제 결과를 재산출하는 작업입니다.

## 우선 검증

- 행사일과 같은 요일의 비행사 원본 OD·체류인구 파일을 확보하고 날짜별로 다시 적재
- 날씨, 도로 통제와 다른 행사가 비교일에 미친 영향 기록
- 동일 `origin × destination × mode`에서 이동시간 차이를 계산
- 행정동과 날짜를 함께 묶은 교차검증
- 음수 지체 관측을 삭제하지 않은 모델 진단과 민감도 분석
- 결과표에 변수 정의, 관측 단위, 표본 수와 불확실성 구간 표시

## 운영 분석

- 공덕·당산·노량진 거점별 회전시간과 회송거리 반영
- 좌석 수, 탑승률, 차량 수와 회전수를 조절하는 계산기
- 승하차 공간, 도로 통제와 운영인력을 포함한 비용 범위 산정
- 셔틀 미운영·부분 운영·전체 운영 시나리오 비교

완료 기준은 원본 데이터 기준의 재현 실행, 날짜 단위 검증 결과, 핵심 그래프와 가정표가 같은 커밋에 남는 것입니다.
