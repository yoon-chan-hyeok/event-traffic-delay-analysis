# 초기 탐색 노트북 검토 기록

초기 노트북은 197개 셀로 구성됐고, 행사일·비교 토요일의 OD 이동량과 체류인구, 시간대별 유입·유출, 이동시간과 속도를 탐색했습니다. 분석 범위를 주변 행정동으로 넓힌 뒤 isotonic regression과 선형 회귀도 비교했습니다.

공개본을 만들면서 아래 항목을 수정했습니다.

| 초기 구현 | 문제 | 공개본 처리 |
|---|---|---|
| 비교일을 토요일로 설명 | 실제 6개 날짜는 모두 일요일 | 탐색적 비행사 주말 참고선으로 정정 |
| 개인 PC의 절대경로 사용 | 다른 환경에서 실행 불가 | 저장소 기준 상대경로 사용 |
| 비교일 합계를 고정값 `6`으로 나눔 | 실제 관측일 수가 달라지면 평균 오류 | `date` 고유값으로 날짜별 평균 계산 |
| 차량 행사일을 대중교통 평시 값과 비교한 셀 | 비교군 불일치 | 같은 수단 필터를 행사일과 평시에 공통 적용 |
| 일부 함수에서 `cdf_1` 대신 전역 `cdf` 참조 | 다른 데이터프레임 값이 섞일 수 있음 | 함수 인자와 지역 변수만 사용 |
| 음수 지체 행 제거 | 선택 편향 가능 | 부호를 유지하고 별도 민감도 분석 대상으로 남김 |
| 학습자료에서 다시 성능 계산 | 일반화 성능을 과대평가 | 날짜 전체를 제외하는 교차검증 사용 |
| 93개 코드 셀의 출력 저장 | 노트북이 약 50MB로 증가 | 공개 노트북은 필요한 셀과 출력만 유지 |

기존 노트북에서 확인한 `R² 0.919` 등의 값은 학습자료 재평가 결과이므로 공개본의 대표 성능으로 사용하지 않습니다. 원본 데이터를 다시 확보하면 날짜 단위 검증으로 결과표를 교체합니다.

시간대별 평균 이동시간은 행사일과 참고일의 출발지 구성이 다르면 정체가 없어도 달라질 수 있습니다. 원본 데이터 재검증에서는 `origin × destination × mode` 단위로 먼저 이동시간 차이를 계산한 뒤 시간대 수준으로 집계해야 합니다.
