# Major-Event Traffic Delay Analysis

> 대형 행사일의 이동시간 변화를 수요 증가만으로 설명하지 않고, 수요 집중과 공급 제약의 결합으로 분석한 교통 데이터 프로젝트입니다.

**Case:** 여의도 불꽃축제 · **Status:** Graduation research prototype

## 핵심 질문

행사일 혼잡은 사람이 많아서만 발생했을까? 이 프로젝트는 생활인구·OD·버스 승하차·정류장·GIS 데이터를 결합해 다음 가설을 검토했습니다.

- 특정 시간과 지역으로 이동 수요가 집중된다.
- 무정차, 도로 통제, 우회 운행으로 공급이 동시에 줄어든다.
- 두 요인이 결합해 주변 환승 거점까지 지연이 전파된다.

## 사용 데이터

- SKT 행정동 OD 및 체류 인구
- 서울시 버스 정류장 승하차 데이터
- TPSS 정류장 단위 교통량
- 서울시 GIS 경계 데이터

원천 데이터의 이용 조건과 크기 때문에 공개 저장소에는 원본 대신 스키마, 처리 절차, 집계 예시만 제공합니다.

## 내가 주도한 부분

- 행사일과 동요일 기준일을 비교하는 EDA 및 시공간 분석
- 기준일 선택이 효과 크기를 부풀릴 수 있음을 발견하고 해석의 한계로 명시
- 버스·지하철 수요, OD 이동시간, 생활인구, 교통량·속도를 교차 검토
- 공덕·당산·노량진을 분산 거점으로 둔 셔틀 운영 시나리오 설계
- 단순 시각화에서 끝내지 않고 데이터 근거와 운영 제약을 함께 제시

## 확인된 결과

| 비교 | Pearson r |
|---|---:|
| 체류 인구 변화 ↔ 목적지 기준 평균 OD 시간 변화 | 0.5864 |
| 체류 인구 변화 ↔ 출발지 기준 평균 OD 시간 변화 | 0.5969 |
| 체류 인구 변화 ↔ 대중교통 출발 지연 | 0.7034 |

단순 회귀 시나리오에서 체류 인구 13,000명 분산은 목적지 기준 약 `0.80분`, 출발지 기준 약 `1.26분`, 대중교통 출발 기준 약 `1.93분`의 감소와 연관되었습니다. 이는 인과효과가 아니라 관측 관계를 이용한 시나리오 추정입니다.

## 운영 제안

- 거점: 공덕·당산·노량진
- 가정: 45인승 버스 100대, 3회전
- 이론상 분산 수요: 13,500명
- 추정 운영비: 약 5,000만 원

회차 시간, 도로 통제, 승하차 공간과 실제 배차 가능성은 추가 검토가 필요한 제약입니다.

## 현재 한계
