# 데이터 준비

원천 데이터는 저장소에 포함하지 않습니다. `data/raw/`에 아래 파일을 배치하고 공개 코드에서 상대경로로 읽는 방식을 권장합니다.

## OD 이동량

필수 열은 다음과 같습니다.

| 열 | 의미 | 단위·형식 |
|---|---|---|
| `origin_hdong_cd` | 출발 행정동 코드 | 문자열 |
| `dest_hdong_cd` | 도착 행정동 코드 | 문자열 |
| `date` | 관측 날짜 | `YYYYMMDD` |
| `start_time` | 출발 시간대 | `HH:MM` |
| `end_time` | 도착 시간대 | `HH:MM` |
| `modal` | 이동수단 코드 | 정수 또는 결측 |
| `od_dist_avg` | 평균 이동거리 | m |
| `od_duration_avg` | 평균 이동시간 | 분 |
| `od_cnts` | 추정 이동량 | 건 |

공개 코드는 초기 노트북의 분류에 따라 `0`을 차량, `1·2·5`를 대중교통으로 처리합니다. 실제 원본을 다시 분석하기 전 데이터 제공기관의 코드 정의와 일치하는지 확인해야 합니다. 수단 결측값은 차량으로 바꾸지 않습니다.

## 체류인구

초기 분석에 사용한 열은 `hdong_cd`, `date`, `time`, `stay_cnts`입니다. 날짜별·시간대별로 먼저 집계한 뒤 행사일과 비교일을 나눕니다.

## 참고일 규칙

초기 연구 문서에는 여러 토요일을 비교했다고 적혀 있었지만, 저장된 출력의 날짜를 다시 확인하면 `20230903`, `20230910`, `20230917`, `20230924`, `20231001`, `20231015`로 모두 일요일입니다. 행사일 `20231007`은 토요일이므로 같은 요일 기준선이 아닙니다. 공개본은 이 자료를 인과적 비교군이 아니라 비행사 주말 참고선으로만 설명합니다.

파이프라인은 참고일 개수를 상수로 두지 않고 실제 `date` 고유값을 계산합니다. 날짜별 집계를 먼저 만드는 이유는 파일 수나 특정 날짜의 행 수가 평균값을 바꾸지 않게 하기 위해서입니다.

## 합성 샘플

`data/sample/`의 CSV는 열 구조와 실행 흐름을 확인하기 위해 만든 합성 데이터입니다. 실제 여의도 교통량, 이동시간 또는 모델 성능을 나타내지 않습니다.
